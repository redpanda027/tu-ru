## 3️⃣ リアルタイム複数ユーザー対応（Supabase）

### 新機能
- **複数デバイス間のリアルタイム同期**: 35人が同時にアクセスして、全員の変更がリアルタイムに反映
- **自動データ保存**: ページを再読み込みしてもデータは消えない
- **スケーラビリティ**: 最大で数百人同時アクセス対応

### 実装内容
| ファイル | 機能 |
|---------|------|
| `supabase-config.js` | Supabase 接続設定 |
| `supabase-sync-ikken.js` | いけんボードのリアルタイム同期 |
| `supabase-sync-group.js` | グループボードのリアルタイム同期 |

## 🚀 ユーザー向け流れ

### 先生側（ボードを開く）
```
1. いけんボード.html を開く
2. 「ボードを共有する」セクションで QR コードまたはリンクを取得
3. 生徒に QR コード / リンク / ボード ID を伝える
4. 生徒が参加すると「参加者」カウンターが増える
```

### 生徒側（ボードに参加）
```
1. QR コードをスキャン OR リンクをタップ OR ID を入力
2. 同じボードにアクセス
3. 意見を追加 → 全員の画面に即座に反映
4. 他の生徒の意見をリアルタイムで見る
```

## 📊 各ボードの使用例

### いけんボード
**使い方**: 学級会でのブレーンストーミング
```
生徒A: 意見を追加 → 全員に同時配信
生徒B: 意見に返信または投票 → リアルタイム表示
先生: リアルタイムで議論の流れを把握
```

### グループ活動ボード
**使い方**: グループでの活動進捗共有
```
グループ1: 「市役所へ実地調査」と投稿 → 状態を「進行中」に
グループ2: 「アンケート回収完了」と投稿 → 状態を「完了」に
先生: 全グループの進捗を一画面で把握
```

### 活動報告ボード
**使い方**: 総合的学習の時間での成果報告
```
各グループ: 学習成果を報告
先生: リアルタイムで全グループの報告を集約
```
